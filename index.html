학생

  • 선생님이 알려 준 차시의 학생용 열기를 누른다.
  • 화면을 밀거나 화살표로 넘기고, 그림 속 자석·코일·단추를 직접 움직여 본다.
  • 선생님이 수업방을 열면 왼쪽 위 사람 모양 단추를 누르고 화면의 참여 코드 네 자리를 넣는다(QR을 찍어도 된다).
  • 휴대폰은 가로로 돌리면 크게 보인다.
  • 복습하거나 인쇄하려면 PDF를 연다(장마다 정답까지 다 연 화면).

선생님

  • 교사용에는 장마다 발표자 메모(발문·예시 답·지도 유의점)가 있다. S 발표자 화면
  • → 다음 단계 · F 전체 화면 · C 판서 · B 칠판 · Esc 한눈에 보기
  • 선생님 페이지: 반마다 수업방을 한 번 만들고 학생 링크를 클래스룸에 올려 두면, 수업 때 반과 차시만 누르면 된다.
  • 수업방: 사람 모양 단추 → «수업방 열기». 참여 코드·QR을 프로젝터로 띄우면 학생 화면이 선생님이 넘기는 장을 따라온다(«모두 따라오기 / 자유롭게», 잠그기). 학생이 예측·○×를 누르면 보기마다 고른 수가 뜨고, «한 낱말 묻기»로 낱말 구름을 띄울 수 있다. 학생 이름·기록은 남지 않는다.
  • 파일 하나에 다 들어 있어 내려받으면 인터넷 없이도 열린다(글꼴만 기본 글꼴로 바뀌고, 수업방은 인터넷이 있어야 한다).
